# Sobaina — Portfolio

Personal portfolio site for Sobaina, a designer-developer hybrid based in Lahore. Showcases UI/UX design work (Figma/Canva) and full-stack development case studies, with a light scroll-based coin/badge gamification layer.

## Stack

- [Vite](https://vitejs.dev/) + React 19 + TypeScript
- Tailwind CSS v4, Radix UI / shadcn-style components
- [wouter](https://github.com/molefrog/wouter) for routing
- Framer Motion for animation

## Commands

```bash
npm run dev      # start the dev server
npm run build    # type-check and build for production
npm run serve    # preview the production build locally
```
